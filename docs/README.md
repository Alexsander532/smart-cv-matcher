# Documentação — Smart CV Matcher · HackatOhm 2026

Documentação de trabalho do Case B da EloGroup, baseada no regulamento local e no case fornecidos pela equipe. Referência: 21/10/2026, horário de Brasília.

**Versão inicial para o grupo:** propostas, prioridades e frentes de trabalho precisam ser revisadas pelos integrantes. Nenhum responsável individual foi presumido. A decisão de direção já informada é construir **primeiro uma PoC de front com dados simulados**, acrescentando um back básico somente se houver tempo.

Para começar o desenvolvimento, ler [13 — Desenvolvimento da PoC](13-desenvolvimento-da-poc.md) e [14 — Backlog e colaboração](14-backlog-e-colaboracao.md). Os capítulos de arquitetura, IA e governança descrevem também uma evolução de produto e não são uma lista de exigências para a primeira demonstração.

**Proposta:** organizar currículos e comprovantes em uma base atualizada, extrair informações com IA e recomendar profissionais e equipes segundo critérios explícitos de cada disputa comercial. Cada ponto precisa de uma regra e de uma evidência rastreável.

**Estado real do projeto:** planejamento e documentação. O repositório ainda não contém uma aplicação implementada. Exemplos, metas e resultados numéricos ilustrativos não são medições de um produto em funcionamento.

## Antes de submeter

1. Resolver com os mentores a divergência dos critérios de avaliação entre case e regulamento.
2. Substituir hipóteses por medições onde houver experimento; identificar claramente o que continua previsto.
3. Revisar os textos com todos os integrantes, registrar autoria, fontes e ferramentas utilizadas.
4. Diagramar o resumo em **duas páginas**, incluindo o parágrafo institucional de 150 a 200 palavras; gravar vídeo com até cinco minutos.
5. Conferir o canal oficial e submeter até **27/10/2026, às 23h**, salvo alteração formal divulgada pela organização.

Os documentos são uma proposta inicial editável. Decisões de produto não devem ser confundidas com exigências oficiais do evento ou com regras de um edital comercial real.
