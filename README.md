# smart-cv-matcher
Sistema de IA para extração, ranqueamento e matching de currículos contra regras de editais. Desenvolvido para o Case EloGroup.

## Documentação do HackatOhm 2026

A proposta, o regulamento, os requisitos e o plano de desenvolvimento estão em [docs/README.md](docs/README.md).

O projeto está na etapa de planejamento. A documentação inclui regras explicáveis de pontuação, comprovação documental, composição de equipes, arquitetura, riscos, estimativas de impacto e roteiro de pitch. Os dados de demonstração são inteiramente fictícios; a aplicação ainda não foi implementada.

A direção inicial do grupo é construir primeiro uma **PoC de front com dados simulados** e, se houver tempo, acrescentar um back básico. O roteiro de implementação está em [desenvolvimento da PoC](docs/13-desenvolvimento-da-poc.md), com tarefas organizadas no [backlog do grupo](docs/14-backlog-e-colaboracao.md). A documentação é uma base para revisão e colaboração dos integrantes.
